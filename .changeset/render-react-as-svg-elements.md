**Breaking (API):** `<Smirk>` renders real SVG elements with the `<svg>` as its root node, dropping the `<span>` wrapper and `dangerouslySetInnerHTML`. `className` and `style` now land on the `<svg>` itself, which fixes the documented `className="size-12 rounded-full"` usage — a `<span>` is `display:inline`, so width and height were ignored, and `border-radius` does not clip without `overflow:hidden`, so the avatar rendered as a 300x300 unclipped square. Unknown props now spread onto the `<svg>`, so `ref`, `onClick`, `id`, `data-*` and `aria-*` reach the DOM and `asChild` triggers work; `viewBox`, `shape-rendering`, `role` and `aria-hidden` stay part of the output contract and are not overridable. A caller-supplied `aria-label` or `aria-labelledby` now switches the SVG to `role="img"` rather than being discarded under `aria-hidden`. `memo` and `useMemo` are gone — both work fine in React Server Components, contrary to the usual claim, but `memo`'s shallow compare is defeated by the inline `style` object most consumers pass. There is still no `'use client'` and no context, so one entry serves Server Components, Client Components and pure-server `renderToString`; `test/react.test.tsx` imports the module under `--conditions=react-server` so that cannot regress.
